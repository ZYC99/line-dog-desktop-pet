# 打工模式键盘映射功能 — 开发规格文档

> 版本: v2.0 最终规格
> 创建: 2026-05-15
> 目标: 打工模式下全局热键注册 + 小狗按键盘 + 可视反馈

---

## 1. 功能概述

打工模式下，线条小狗坐在键盘上方。用户按下热键时：
1. 键盘浮现 + 对应按键高亮
2. 小狗切到 keypress 姿势
3. 执行映射动作
4. 松手后键盘保持 10 秒，无新按键则渐变淡出

---

## 2. 设计决策汇总

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 整合方式 | **方案 B**：复用 BongoCat 键盘 PNG 素材，PySide6 QLabel 叠层渲染 |
| 2 | 窗口布局 | **布局 C**：正方形窗口，小狗在上、键盘缩小叠底 |
| 3 | 全局热键 | ctypes + Windows `RegisterHotKey`，零额外依赖 |
| 4 | 键盘显示策略 | 右键菜单可开关，默认隐藏，首次按键浮现 |
| 5 | 自动隐藏 | 松手后 10 秒内无新按键 → 键盘**渐变淡出** |
| 6 | 按键高亮 | 复用 BongoCat `left-keys/*.png` + `right-keys/*.png` |
| 7 | 按键范围 | 全键盘 58+4 键 PNG，完整拷贝 |
| 8 | 小狗动画 | 按键时切 keypress GIF，松手后 10s 回 work GIF |
| 9 | 键盘缩放 | 随窗口等比缩放，小狗:键盘比例固定 |
| 10 | 配置方式 | 拖拽式可视化键盘配键窗口 |
| 11 | 默认状态 | 进打工不显示键盘，第一次按键才浮现 |
| 12 | 过渡效果 | 渐变淡出（改变窗口/图层透明度） |
| 13 | 鼠标检测 | **Phase 3/4 待开发**（Live2D 与 PySide6 不兼容） |
| 14 | 键盘素材 | 全量复用 BongoCat `public/models/keyboard/resources/` |

## 3. 用户体验流程图

```
进入打工模式
    │
    ├─ 键盘状态: 隐藏 (默认)
    │   └─ 小狗显示 work GIF (135×135 窗口)
    │
    ├─ 用户按下热键 (如 Ctrl+Alt+C)
    │   ├─ 键盘浮现 (透明度 0→1, 窗口扩展高度)
    │   ├─ 对应键位 PNG 高亮
    │   ├─ 小狗切 keypress GIF
    │   ├─ 执行映射动作 (打开程序/发送文本等)
    │   └─ 重置 10 秒计时器
    │
    ├─ 10 秒内无新按键
    │   ├─ 键盘透明度 1→0 渐变
    │   ├─ 窗口缩回到 work 尺寸
    │   └─ 小狗切回 work GIF
    │
    ├─ 10 秒内有新按键
    │   └─ 回到上一步 (重置计时器)
    │
    └─ 退出打工 / 右键「隐藏键盘」
        └─ 立即隐藏键盘，回到 work 状态
```

## 4. 窗口布局规范

```
┌──────────────────────┐
│                      │
│     🐶 小狗区域       │  占窗口 60% 高度
│     (QLabel GIF)     │
│                      │
├──────────────────────┤
│  ┌────────────────┐  │
│  │   ⌨️  键盘底图  │  │  占窗口 35% 高度
│  │  (background)  │  │  等比缩放，保持宽高比
│  │  + 按键高亮叠层  │  │
│  └────────────────┘  │
│     留白 5%          │
└──────────────────────┘
```

- 窗口底图宽度 = 小狗尺寸 (pet_size)
- 窗口总高度 = 小狗尺寸 + 键盘高度 + 5% margin
- 键盘保持 612:354 宽高比，缩放到和小狗等宽

## 6. 技术架构

### 6.1 新增文件

| 文件 | 职责 |
|------|------|
| `pet_keymapper.py` | 热键配置加载、映射管理、回调分发、10s 倒计时 |
| `keyboard_hook.py` | Windows `RegisterHotKey` 注册/注销（ctypes） |
| `pet_keyboard_overlay.py` | 键盘叠层 UI：QLabel 组合渲染、透明度控制 |

### 6.2 可能改动的文件

| 文件 | 改动点 |
|------|--------|
| `pet_window.py` | `_enter_work`/`_exit_work` 中管理键盘显示/隐藏，过渡动画 |
| `pet_menu.py` | 添加「显示键盘」开关项、「配置热键」按钮 |
| `config.py` | 新增键盘相关常量（淡出速度、默认状态等） |
| `pet_animation.py` | 添加 keypress 分类支持（如有新 GIF 素材） |

### 6.3 核心类设计

```
PetKeyboardOverlay(QWidget)
├── _bg_label: QLabel         // 键盘底图
├── _key_labels: dict         // {key_name: QLabel} 按键高亮缓存
├── show(duration_ms)         // 渐显键盘
├── hide(duration_ms)         // 渐隐键盘
├── press_key(name)           // 高亮指定键
├── release_key(name)         // 取消高亮
└── _fade_animation: QPropertyAnimation  // 透明度动画

PetKeyMapper(QObject)
├── _mappings: dict           // {hotkey_id: action_config}
├── _active_keys: set         // 当前按下的键
├── _hide_timer: QTimer       // 10 秒倒计时
├── load_config(path)         // 加载 JSON 配置
├── on_key_down(key_id)       // 按键事件分发
├── on_key_up(key_id)         // 松键事件
└── _execute_action(config)   // 执行映射动作

KeyboardHook(QObject)
├── register_hotkey(mod, vk, callback)
├── unregister_all()
└── _native_handler(msg)      // WM_HOTKEY 处理
```

## 7. 热键配置格式

`config/hotkeys.json`：

```json
{
  "version": 1,
  "mappings": [
    {
      "id": "calc",
      "hotkey": { "modifiers": ["ctrl","alt"], "key": "C" },
      "key_name": "KeyC",
      "action": "open_program",
      "params": { "path": "calc.exe" },
      "description": "打开计算器"
    },
    {
      "id": "screenshot",
      "hotkey": { "modifiers": ["ctrl","shift"], "key": "S" },
      "key_name": "KeyS",
      "action": "simulate_keys",
      "params": { "keys": ["win","shift","s"] },
      "description": "截图工具"
    },
    {
      "id": "quick_reply",
      "hotkey": { "modifiers": ["ctrl","alt"], "key": "G" },
      "key_name": "KeyG",
      "action": "type_text",
      "params": { "text": "好的，马上处理！" },
      "description": "快速回复"
    }
  ]
}
```

### 支持的动作类型

| action 值 | 作用 | params 示例 |
|-----------|------|-------------|
| `open_program` | 启动程序 | `{"path": "calc.exe"}` |
| `open_url` | 打开网页 | `{"url": "https://..."}` |
| `simulate_keys` | 模拟组合键 | `{"keys": ["ctrl","c"]}` |
| `type_text` | 输入文本 | `{"text": "你好"}` |

## 9. 可视化配置界面

### 9.1 布局

```
┌─────────────────────────────────────────┐
│  ⚙️ 热键配置                        ✕│
├─────────────────────────────────────────┤
│                                         │
│   ┌─────── 键盘映射视图 ──────────┐    │
│   │                               │    │
│   │   [Esc] [F1]...[F12]          │    │
│   │   [1][2][3]...[0][-][=] [⌫] │    │    │   │   [Tab][Q][W]...[P][⌂]       │    │
│   │   [Caps][A][S]...[L][Enter]   │    │
│   │   [Shift][Z]...[M][Shift]     │    │
│   │   [Ctrl][Win][Alt][Space]...  │    │
│   │                               │    │
│   └───────────────────────────────┘    │
│                                         │
│   ┌── 动作面板 ─────────────────────┐   │
│   │ 📂 打开程序    📝 发送文本      │   │
│   │ ⌨️ 模拟按键    🌐 打开URL      │   │
│   └────────────────────────────────┘   │
│                                         │
│   选中键位: [ KeyC ]                    │
│   当前绑定: 打开计算器 (calc.exe)      │
│                                         │
├─────────────────────────────────────────┤
│                    [保存]  [取消]       │
└─────────────────────────────────────────┘
```

### 9.2 交互流程

1. 用户从**动作面板**拖拽一个动作类型到键盘视图的键位上
2. 弹出参数配置对话框（如程序路径、文本内容）
3. 键位显示高亮 + 动作图标，表示已绑定
4. 点击「保存」写入 `config/hotkeys.json`
5. 已绑定的键位显示不同颜色/图标

## 11. 风险与待定项

| 风险 | 影响 | 缓解 |
|------|------|------|
| RegisterHotKey 键位冲突 | 热键无法注册 | 注册失败 Fallback 提示用户换键 |
| 大量 PNG 素材增加打包体积 | ~1MB | 可接受，PNG 本身已优化 |
| 键盘素材与小狗风格不匹配 | 画风割裂 | 后期可替换键盘素材（pixel-art 备选） |
| 拖拽配置 UI 复杂 | 开发周期长 | 可降级为列表式配置（Phase 3 fallback） |
| 鼠标检测 (Live2D) | 暂时不可行 | Phase 3/4 待开发，留意 Live2D SDK 进展 |
