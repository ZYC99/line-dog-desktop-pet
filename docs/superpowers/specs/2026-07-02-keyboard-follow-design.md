# 键盘跟随功能设计

## 目标

当 LineDogPet 处于打工模式并显示键盘时，使用 `assets/generated/typing_dog_halfbody_left45.png` 替换原有打工 GIF；用户在系统任意窗口按下或松开按键时，桌面宠物的键盘同步高亮或恢复。

本功能只负责视觉反馈，绝不拦截、修改或重新映射系统键盘输入。

## 功能范围

- 仅在“打工模式 + 显示键盘”同时满足时使用静态打字小狗。
- 在打工模式中隐藏键盘后，恢复现有 `work` GIF。
- 退出打工模式后，恢复原有普通动画逻辑。
- 仅在“打工模式 + 显示键盘”时启用全局键盘监听。
- 使用已导入的 BongoCat 键盘素材高亮按键，并支持多个按键同时高亮。
- 本阶段不实现功能快捷键配置，也不创建 `hotkeys.json`。

## 架构设计

### 资源配置

在 `config.py` 中提供静态打字小狗的资源路径。路径基于 `BASE_DIR` 生成，继续兼容 PyInstaller 的 `_MEIPASS` 解包目录。

### Windows 全局键盘钩子

新增 `keyboard_hook.py`，实现仅用于 Windows 的 `WH_KEYBOARD_LL` 低级键盘钩子服务。

- 在独立线程安装钩子并运行 Windows 消息循环。
- 将虚拟键码、扫描码、扩展键标记以及按下/松开状态通过 Qt Signal 发送到主线程。
- 钩子回调始终继续调用下一个钩子，绝不吞掉用户输入。
- 启动和停止操作必须可重复调用，不创建重复钩子。
- 隐藏键盘、退出打工模式或退出应用时立即卸载钩子。
- 在非 Windows 平台或钩子安装失败时安静降级，不影响宠物窗口正常使用。

`keyboard_hook.py` 只负责 Windows 原生监听的生命周期，不依赖窗口控件或键盘图片。

### 键码映射与键盘叠层

扩展 `pet_keyboard_overlay.py`，统一负责虚拟键码到素材文件的映射，以及当前按下按键的视觉状态。

- 原生事件信息足够时，分别识别左右 `Shift`、`Ctrl` 和 `Alt`。
- 方向键使用 `right-keys` 素材，主键盘支持的按键使用 `left-keys` 素材。
- 使用集合保存当前按下的素材名，从而支持组合键，并避免按键自动重复产生重复图层。
- 在键盘素材原始的 612x354 画布上合成底图和所有按键图层，再统一缩放到当前显示尺寸。
- 松开按键时只移除对应图层；停止监听时清空全部按下状态。
- 未知键码或缺失的可选按键图片直接忽略，不影响其他按键显示。

### 主窗口集成

`PetWindow` 根据 `stats.work_mode and stats.keyboard_visible` 统一判断键盘跟随是否启用。

- 启用时：显示静态打字小狗、显示键盘并启动全局监听。
- 打工模式但隐藏键盘时：停止监听、清空高亮、隐藏键盘并恢复现有 `work` GIF。
- 普通模式时：停止监听、清空高亮、隐藏键盘，并恢复现有普通动画行为。
- 静态 PNG 按比例平滑缩放到现有 180px 小狗区域，保留图片透明边距。
- 所有窗口和图片更新只在 Qt 主线程执行。

## 状态流程

1. 用户进入打工模式。
2. 如果未显示键盘，继续播放现有 `work` GIF。
3. 用户开启“显示键盘”后，窗口扩展键盘区域，将小狗切换为静态 PNG，并启动全局键盘钩子。
4. 收到按键按下事件时添加对应高亮图层；收到松开事件时移除对应图层。
5. 用户隐藏键盘或退出打工模式时，立即停止监听、清空图层，并恢复对应动画。

持久化数据仍然只有现有的 `keyboard_visible` 用户偏好。当前按下的按键和钩子运行状态都是临时运行态，不写入 JSON。

## 异常处理

- 钩子启动失败时，静态小狗和键盘仍然正常显示，只是不再高亮按键。
- 重复启动或停止不会产生多个钩子或遗留线程。
- 不支持的按键直接忽略。
- 应用关闭时，即使窗口已开始销毁，也会尽力卸载钩子。
- 原生钩子回调中不加载图片，也不执行耗时渲染。

## 测试要求

- 模拟 PyInstaller `_MEIPASS`，验证静态小狗和键盘资源路径。
- 覆盖素材支持的字母、数字、符号、方向键以及左右修饰键映射。
- 覆盖按下、自动重复、组合键、松开和清空高亮状态。
- 钩子生命周期测试使用注入的假原生后端，不在自动化测试中安装真实全局钩子。
- 主窗口测试覆盖静态 PNG 切换、隐藏键盘后恢复 `work` GIF，以及停止监听。
- 运行完整回归测试、Python 编译检查和 `git diff --check`。
- 在 Windows 上手动确认全局按键高亮、正常打字不受影响，以及停用后不再响应按键。
