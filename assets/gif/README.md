# 素材放置说明

将 GIF 素材按动作类型放入对应的子文件夹。

## 命名规则

```
{编号}_{描述}.gif

例子：
idle/01_站立.gif
walk/01_走路.gif
drag/01_被拖.gif
```

> 编号从 01 开始，同文件夹内多张 GIF 随机循环播放

## 动作分类

| 文件夹 | 当前数量 | 用途 | 触发方式 |
|--------|----------|------|----------|
| `idle/` | 4 | 待机 | 默认状态 |
| `walk/` | 8 | 走路 | 随机走动 |
| `jump/` | 1 | 跳跃/向上移动 | 随机移动方向向上 |
| `drag/` | 2 | 被拖拽 | 鼠标按住拖动 |
| `sleep/` | 3 | 睡觉 | 长时间无操作 |
| `happy/` | 24 | 开心 | 好感度高时自动触发 |
| `angry/` | 2 | 生气 | 好感度低时自动触发 |
| `sad/` | 1 | 难过 | 预留情绪素材 |
| `astonishing/` | 2 | 震惊 | 鼠标长时间离开后再次进入 |
| `hungry/` | 1 | 饿了 | 饱食度低 |
| `dirty/` | 1 | 脏了 | 清洁度低 |
| `eat/` | 2 | 喂食 | 右键菜单 → 喂食 |
| `bath/` | 4 | 洗澡 | 右键菜单 → 洗澡 |
| `greet/` | 16 | 打招呼 | 启动、悬停或右键菜单 → 打招呼 |
| `play/` | 17 | 玩耍 | 右键菜单 → 玩耍 |
| `full/` | 1 | 吃饱 | 饱食度已满时喂食 |
| `work/` | 3 | 打工 | 右键菜单或托盘进入打工模式 |
| `bye/` | 2 | 告别 | 退出应用前播放 |
| `special/` | 1 | 彩蛋 | 特殊触发 |
| `climb/` | 0 | 爬墙 | 预留屏幕边缘动作 |

## 最少启动素材

至少需要这四类各 1 张：

- ✅ `idle/` — 1张以上
- ✅ `walk/` — 1张以上
- ✅ `drag/` — 1张以上
- ✅ `eat/` `bath/` `greet/` `play/` — 各1张（右键互动用）

其他分类可选，没有素材的文件夹程序会自动跳过。
