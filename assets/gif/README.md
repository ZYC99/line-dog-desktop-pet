# 素材放置说明

将 GIF 素材按动作类型放入对应的子文件夹。

## 命名规则

```
{编号}_{描述}.gif

例子：
idle/01_站立.gif
walk/01_走路.gif
drag/01_被拖.gif
```

> 编号从 01 开始，同文件夹内多张 GIF 随机循环播放

## 动作分类

| 文件夹 | 用途 | 触发方式 |
|--------|------|----------|
| `idle/` | 待机 | 默认状态 |
| `walk/` | 走路 | 随机走动 |
| `drag/` | 被拖拽 | 鼠标按住拖动 |
| `sleep/` | 睡觉 | 长时间无操作 |
| `happy/` | 开心 | 好感度高时自动触发 |
| `eat/` | 喂食 | 右键菜单 → 喂食 |
| `bath/` | 洗澡 | 右键菜单 → 洗澡 |
| `greet/` | 打招呼 | 右键菜单 → 打招呼 |
| `play/` | 玩耍 | 右键菜单 → 玩耍 |
| `climb/` | 爬墙 | 碰到屏幕边缘 |
| `angry/` | 生气 | 好感度极低 |
| `hungry/` | 饿了 | 饱食度低 |
| `dirty/` | 脏了 | 清洁度低 |
| `special/` | 彩蛋 | 特殊触发 |

## 最少启动素材

至少需要这四类各 1 张：

- ✅ `idle/` — 1张以上
- ✅ `walk/` — 1张以上
- ✅ `drag/` — 1张以上
- ✅ `eat/` `bath/` `greet/` `play/` — 各1张（右键互动用）

其他分类可选，没有素材的文件夹程序会自动跳过。
